# Python

Playground for Python coding problems, mirroring the DSA/coding practice in `src/main/java`.

## Layout

```
python/
├── dsa/              # data structures & algorithms problems
│   └── two_sum.py    # sample problem (run directly)
└── README.md
```

## Running

Run any file directly:

```bash
python3 python/dsa/two_sum.py
```

Or run the tiny built-in asserts from the repo root:

```bash
python3 python/dsa/two_sum.py && echo "all tests passed"
```
